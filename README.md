# PAUSE

**넘기기 전에, 남겨보세요.** YouTube 롱폼 시청을 메모와 성찰로 연결하는 Chrome Manifest V3 확장 프로그램입니다. 기록을 외부 서버로 전송하지 않습니다.

## 개발과 설치

Node.js 22.12+ 또는 24 LTS, npm을 사용합니다.

```sh
npm ci
npm test
npm run typecheck
npm run build
```

Chrome `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드**로 `dist/` 폴더를 선택하세요. 이미 열려 있던 YouTube 탭은 새로고침하세요. 소스를 변경한 뒤 다시 빌드하고 확장 프로그램과 YouTube 탭을 새로고침합니다. `npm run dev`는 popup UI 개발용이며 확장 프로그램 실행을 대체하지 않습니다.

## 현재 동작

- YouTube watch URL의 video 요소와 SPA 이동, video 요소 교체를 추적합니다. 홈에서 watch로 이동하는 경우도 처리하려고 YouTube 전체 경로에 content script를 주입하지만 UI와 시청 추적은 watch 페이지에서만 활성화합니다.
- 실제 재생한 벽시계 시간이 30초 이상이고 영상 길이의 70% 이상일 때 종료 성찰을 표시합니다. 2배속으로 100초 영상을 50초 시청하면 70초 조건을 충족하지 않습니다. 재시청 시간은 누적하며 고유 구간 커버리지를 계산하지 않습니다. seek 및 재생 속도와 맞지 않는 위치 도약은 제외합니다.
- 영상 ID별 종료 개입은 탭의 content script 수명 동안 한 번입니다. 새로고침하면 시청 누적과 개입 상태는 초기화되지만 저장한 기록과 메모 초안은 유지합니다.
- 성찰 메모는 즉시 저장할 수 있고, 건너뛰기는 5초 뒤 활성화됩니다. 기록하지 않아도 불이익은 없습니다.
- 개입 중 video를 일시정지하고, 일반 클릭으로 요청한 동일 사이트 watch/shorts 링크 한 개를 보관했다가 저장 또는 건너뛰기 후 이동합니다. 수정키 클릭·새 탭 이동은 가로채지 않습니다.
- PAUSE Notes에서 메모와 저장 시점의 재생 위치를 저장하고 타임스탬프로 이동합니다. 초안은 영상별로 저장됩니다.
- popup에서 전체 사용과 종료 성찰을 설정하고 기록 수를 확인합니다.

## 데이터와 권한

`chrome.storage.local`의 `pause:v1:` 키를 사용합니다. `VideoRecord`, `TimestampNote`, `Reflection`, `ShortsSession`, `UserSettings` 모델이 있으며 쇼츠 UI는 구현하지 않았습니다. 개별 레코드를 별도 키에 저장해 서로 다른 레코드의 동시 쓰기 충돌을 줄입니다. 동일 영상 초안을 여러 탭에서 편집하면 마지막 쓰기가 적용됩니다. 저장 용량 초과 등 오류 시 재시도 안내를 표시합니다. 확장 프로그램을 삭제하면 기록이 삭제됩니다. 백업/내보내기 UI는 없습니다.

권한은 `storage` 하나이며 content script 대상은 `https://www.youtube.com/*`입니다. background/service worker, 서버, 로그인, AI 호출, 원격 코드가 없습니다.

## 검증 범위와 제한

`npm test`는 Vitest/jsdom에서 재생 누적, seek, 중복 종료, URL/요소 교체, 저장소 재생성 후 데이터 보존, 5초 대기와 즉시 성찰 저장을 확인합니다. 브라우저 저장소는 테스트용 mock이며 실제 Chrome 재시작을 검증한 결과가 아닙니다.

YouTube 내부 자동 다음 영상 예약, 키보드 이동, 브라우저 뒤로/앞으로, 외부 스크립트 이동 및 페이지 전체 탐색을 모두 차단할 수 없습니다. 자동 다음 영상은 이미 이동했을 수 있고, 개입 중 새 video를 일시정지하는 방식은 최선 노력입니다. 사용자의 자동재생 설정을 변경하지 않습니다. 광고와 본 영상이 같은 video를 공유하면 광고 재생 시간이 누적에 포함될 수 있습니다. 라이브 및 무한 길이 영상은 종료 성찰 대상이 아닙니다. 브라우저의 백그라운드 타이머 제한과 YouTube DOM 변경에 영향을 받을 수 있습니다.

### 실제 Chrome 수동 검증 체크리스트 (아직 미검증)

1. `dist/` 로드 후 popup 설정 저장과 YouTube 탭 반영, 홈 → watch 이동.
2. 30초 이상 및 길이 70% 이상 재생 후 종료, 5초 대기/즉시 저장/건너뛰기, 중복 이벤트.
3. 앞으로/뒤로 seek, 일시정지, 0.5x/2x 재생, 탭 비활성화.
4. 메모 작성 중 닫기/열기, 새로고침 후 저장 메모와 초안 복원, 타임스탬프 이동.
5. 재생목록·자동재생 켜짐/꺼짐, 전체화면, 극장 모드, 광고, SPA 이동·video 교체.
6. 개입 중 직접 영상 링크 클릭 후 저장/건너뛰기 시 요청 이동 복원, Tab 키 포커스 이동.
7. 네트워크 도구에서 PAUSE가 외부로 기록을 전송하지 않는지 확인.
